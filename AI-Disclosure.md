# AI Disclosure

This project was built with AI assistance. This page explains what that means, so players, GMs and
contributors know what they are using.

## What AI was used

The code, documentation and tests in this repository were written with a locally hosted AI model
distilled from Claude.

## Who did what

- **The AI** wrote the code: the system's modules, templates, styles and tests, along with the
  documentation, under the maintainer's direction.
- **The maintainer** designed the system, decided how each rule should work, directed the AI,
  reviewed its output, and play-tests the result in FoundryVTT. The maintainer is responsible for
  what is committed here.

The AI does not commit or push on its own authority. Changes are reviewed before they are committed.

## Testing and limitations

The rule logic has automated unit tests. AI-written code can be wrong in subtle ways, so please report
anything that looks off through the GitHub issue tracker.

## Rules content and copyright

Carl RPG is an unofficial fan project and is not affiliated with Renegade Game Studios or the
Dungeon Crawler Carl books. The system implements game mechanics. It does not bundle text from the
rulebook or the novels, and you need your own copy of the rulebook to play. If you find content
here that you believe is copied from a copyrighted work, please open an issue so it can be
removed or rewritten.

## For AI agents and contributors

`AGENTS.md` and `docs/ai/` exist for AI agents working on this repository. `AGENTS.md` lists the
project's rules for agents, and `docs/ai/` is a per-feature reference of how the system is built,
kept in sync with the code. Human contributors may find it useful too, but it is written for
machines and the code is the source of truth.

Contributions written with AI assistance are welcome. Please say so in your pull request and make
sure you have read and tested what you submit.
